# 霍金个人简历展示页

零依赖的纯静态个人简历单页，使用原生 HTML、CSS、JavaScript 构建。默认深色高科技视觉，包含粒子背景、滚动入场动画、打字机标题、明暗主题切换与降低动效选项。

## 本地预览

在项目根目录执行：

```powershell
python -m http.server 8080
```

然后访问 http://localhost:8080 。

## 线上地址

网站已配置为 GitHub Pages 主站地址：

`https://HawkingDUT.github.io/`

## 部署到 GitHub Pages

1. 在 GitHub 新建名为 `HawkingDUT.github.io` 的仓库。
2. 将本项目推送到该仓库的 `main` 分支。
3. 打开仓库的 **Settings → Pages**。
4. 将 **Source** 设置为 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`。
5. 保存后等待 GitHub 生成公开访问地址。

公开页面只展示邮箱和 GitHub，不包含手机号、家庭住址等敏感信息。
